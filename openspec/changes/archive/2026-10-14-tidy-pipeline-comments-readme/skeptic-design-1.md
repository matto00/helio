### Change Requests
1. **design.md D5 / tasks.md 2.3: the literal repro command does not pin the run's port.** `nice -n 19 npx playwright test …` sets no `DEV_PORT`. `playwright.config.ts` then falls back to `localhost:5173`, which could be the main checkout's or another lane's dev server, and the AC5 evidence would measure the wrong app with only a warning in the log (CON-165). Rewrite the command:
   - Run from `WORKTREE_PATH`, the repo root where `playwright.config.ts` lives.
   - Use `DEV_PORT=6883`.
   - Start the servers first with `scripts/concertino/start-servers.sh … 6883 9790 HEL-1451` and confirm them with `assert-phase.sh servers`.
   - Stop them afterwards with `stop-servers.sh`.
   - Record the resolved `baseURL` and port in `evidence/e2e-flake-probe.md`.
2. **design.md D5: the `-g` pattern is not bounded to 430px.** `-g "430.*surface 7|surface 7"` matches the `|surface 7` alternative, which also selects the 768px instance. That doubles the run count and mixes widths, while the ticket and AC5 ask for 430px. Specify a pattern that matches only `at 430px surface 7: Connectors page` (e.g. `-g "at 430px surface 7: Connectors page"`). Then state the expected test count: 1 test x `--repeat-each=20` = 20 runs, so the executor can check the `N passed` line against it.
