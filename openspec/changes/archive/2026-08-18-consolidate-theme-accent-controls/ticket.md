# HEL-728: Reconsider where theme/accent controls live (Settings vs. top-bar-only)

## Description

From the beta UI/UX polish sweep (PR #382).

**Scope**
Theme/accent controls currently exist in more than one place (the Settings > Preferences editor and top-bar affordances), with no clear single source. Decide and consolidate on one primary location (recommendation: top-bar quick-toggle for theme, Settings for accent/persisted preferences) and remove the redundant surface.

## Acceptance Criteria

- Theme and accent controls each live in exactly one primary, documented location.
