### Change Requests

1. **Reconcile with `openspec/specs/backend-file-size-compliance/spec.md`** (lines 7-8 and 22-28: service files and `PanelService.scala` ≤300; new split files ≤300). In design.md Goals/Risks and the ticket AC, either:
   (a) make ≤300 the target for `PanelService.scala` and say how D2 permits it. For example, the two `private[services]` delegates' scaladoc (about 25 lines, original 266-276 and 324-337) moves with the bodies into `PanelCreateBuilder`, leaving a one-line `[[PanelCreateBuilder.buildAllForCreate]]` pointer. My estimate is about 356 lines with the scaladoc kept, so this alone may not be enough; or
   (b) state explicitly that ≤300 is unreachable under the D2 guard constraints. Give the measured floor, record the remaining gap as a follow-up candidate, and say why no spec delta is needed despite `skip_specs: true`.
   Either way, the evidence (D7d) must report `PanelService.scala`'s final line count against the 300 spec figure, not only against 400.
2. **Pin `.recover` scope for `update` in D3/D5.** Add an explicit invariant that `.recover { case ex: IllegalArgumentException => ... }` wraps only the `patchApplier.apply(panelId, spec).map { ... }` future inside the validation-success branch. It must never wrap the future returned by `PanelUpdateValidation`. Otherwise an exception thrown inside the moved chain could be converted into a 400 where today it is a failed Future and a 500, and the full suite would likely not catch that. The same applies to `batchUpdate`: `.recover` stays on `panelRepo.batchUpdate(items, now).map{...}` only, not on `batchControlsCheck`. D5 currently pins only the audit position.
3. **Add access-modifier changes to D4's allowed list** and specify the modifier: moved `private def`s become `private[panels]` (or the module class is `private[panels] final class` with public members). Say whether the MATCH script compares bodies from the first `=` onward, so a signature-line modifier change is not reported as DIFF. Each changed modifier must be listed in `move-evidence.md` like the other D4 exceptions.
