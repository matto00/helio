Reading: sent were POST /api/auth/register, GET /api/auth/me (context.request), GET /api/auth/me (page.request) and the
page's own loads. Only the page's own requests appear (the single GET /api/auth/me is the app's own bootstrap call).
So neither context.request.* nor page.request.* fires context "request": setup calls must be counted by wrapping
`fetch` on the actor's request context, page traffic via context.on("request"). No double count is possible.
