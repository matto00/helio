### Requirement: DataFieldType includes content field types
**Reason**: The Type Registry (DataTypes page) is retired; binary_refs — the only backend-persisted piece of this capability — is re-keyed to data_source_id and no longer scoped by DataType field types.
**Migration**: binary_refs re-keys from data_type_id to data_source_id in this migration; the frontend Type Registry field editor and unstructured-DataType list are deleted in P1.6.
