# Files Modified — insert-step-at-position (HEL-410)

## Backend

- `backend/src/main/scala/com/helio/api/protocols/PipelineStepProtocol.scala` — `CreatePipelineStepRequest` gains `position: Option[Int] = None` (default preserves every existing 2-arg construction site across services/tests); formatter bumped to `jsonFormat3`.
- `backend/src/main/scala/com/helio/infrastructure/PipelineStepRepository.scala` — new `insertAtInternal(pipelineId, kind, config, index)`: one transactional DBIO that reads the pipeline's steps sorted by position, splices the new row in at `index`, and renumbers every step's position 0..n (the `reorderInternal` idiom) — heals pre-existing position gaps as a side effect. `insertInternal` (append) untouched.
- `backend/src/main/scala/com/helio/services/PipelineService.scala` — `addStep`'s existing validation/ACL chain is unchanged; both persist call sites (owner path, editor-grantee path) now delegate to a new private `persistNewStep` that branches on `req.position`: `None` → `insertInternal` (unchanged); `Some(index)` → reads the current step count fresh (`listByPipelineInternal`, read kept close to the insert per the accepted TOCTOU posture) and validates `0 <= index <= count`, else `422 UnprocessableEntity` (the same variant `reorderSteps` uses) with nothing persisted; in range → `insertAtInternal`.
- `backend/src/test/scala/com/helio/api/PipelineStepRoutesSpec.scala` — 6 new tests: insert at 0 (shifts existing steps down), insert in the middle, insert at count (append-equivalent), negative position → 422 + nothing persisted, position > count → 422 + nothing persisted, and a gap-healing test (delete steps to leave positions 0/2/5, then insert at index 1 → contiguous 0..3). Each asserts persistence via a follow-up GET.
