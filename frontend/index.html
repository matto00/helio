The center of your workflow.

Helio holds the data from every project you run, keeps it private and current, and turns it into dashboards when you or your agent ask. Here's one being built, one call at a time.

  1. “Give me a dashboard for signups, API latency and errors.”

    One request to your agent. The steps below are the tool calls it makes through Helio.

  2. create_pipelineSignups

    Read the signups, define two outputs

    A pipeline over the daily signups table, with a 30-day total and a daily bar chart.

  3. create_pipelineAPI latency

    Chart the p95 latency

    Hourly p95 latency over the last day, as a line chart.

  4. create_pipelineErrors

    Count errors by route

    5xx errors grouped by route, so the worst endpoint is the tallest bar.

  5. set_pipeline_scheduleevery 15m

    Keep it current

    The pipelines re-run on a schedule, so the dashboard stays up to date without anyone opening it.

  6. place_outputs4 panels → Launch week

    Lay it out

    Four panels on a new dashboard. Each one traces back to its pipeline, so you can check where every number came from.
