# Domain: Shapes

Smart-shape pipeline expansion: `PipelineShape` (the shape trait),
`PassthroughShape`, `SingleRowShape`, `TopNShape`, `TimeSeriesShape`,
`PivotMatrixShape`, `ShapeParamDescriptor`, `ShapeStepExpansion`,
`OutputContract`.

**Belongs here:** shape definitions and their expansion into concrete
pipeline steps.
**Does not belong here:** the steps a shape expands into, which live in
`domain.steps`.
